# 🌐 Jerrel Adriel — Portfolio

> Personal portfolio website. Single-page, bilingual (EN/ID), dark mode, fully responsive.

**🔴 Live:** [jerreladriel.github.io](https://jerreladriel.github.io)

![HTML5](https://img.shields.io/badge/HTML5-orange) ![CSS3](https://img.shields.io/badge/CSS3-blue) ![JS](https://img.shields.io/badge/JavaScript-Vanilla-yellow) ![GitHub Pages](https://img.shields.io/badge/Deploy-GitHub_Pages-green)

## ✨ Features

- 🌍 **Bilingual EN/ID** dengan toggle (default English, localStorage persistence)
- 🎨 **Dark mode** modern dengan purple accent
- 📱 **Responsive** (desktop, tablet, mobile)
- 🖼️ **Project lightbox** gallery dengan keyboard navigation
- ⏱️ **Work experience timeline** dengan pulsing dot untuk current job
- 📸 **Profile photo** with transparent background (AI-processed)
- 🎮 **Mini Jump Game** as bonus showcase

## 📂 Sections

1. **Hero** — Name + tagline + CTAs
2. **About** — Bio, photo, badges (location, role, education), stats
3. **Work Experience** — Timeline of 3 positions
4. **Projects** — 5 projects dengan preview lightbox
5. **Skills** — Backend, Frontend, AI & ML, Tools
6. **Contact** — Email, WhatsApp, LinkedIn, GitHub

## 🛠️ Tech Stack

- **HTML5 + CSS3 + Vanilla JavaScript** (no framework)
- **GitHub Pages** untuk hosting
